# Alt Numpad (Windows) 💻⌨️

Небольшая утилита для ноутбуков без физического цифрового блока (Numpad). Программа позволяет переключать стандартную верхнюю строку цифр (1-0) в режим Numpad. Это дает возможность вводить **Alt-коды** и использовать Numpad-клавиши в играх или рабочих приложениях.

Программа написана на **AutoHotkey v2.0** и скомпилирована в `.exe` для удобства.

**Видео-демонстрация работы:** *[Ссылка на видео скоро появится!]*

## Особенности и управление

*   **Включение / Выключение:** Нажмите и отпустите **Правый Alt (Alt Gr)**. При переключении появится небольшая всплывающая подсказка (ToolTip) со статусом: `Numpad: ВКЛЮЧЕН` или `Numpad: ВЫКЛЮЧЕН`.
*   **Обычный ввод Numpad:** Когда режим включен, нажатие обычных цифр `1`, `2`, `3` и т.д. отправляет сигналы `{Numpad1}`, `{Numpad2}` и т.д.
*   **Ввод Alt-кодов:** Когда режим включен, зажмите **Левый Alt** и нажимайте цифры верхней строки, чтобы набирать спецсимволы (Alt-коды), как если бы вы делали это на настоящем Numpad.

## Установка и запуск

Два варианта использования:

1.  **Готовый .exe файл:** Просто скачайте `.exe` из раздела [Releases] и запустите его. Установка AutoHotkey не требуется.
2.  **Запуск скрипта:** 
    *   Установите [AutoHotkey v2.0](https://www.autohotkey.com/).
    *   Скачайте файл скрипта `.ahk` из этого репозитория.
    *   Дважды кликните по скрипту для запуска.

## Как добавить в автозагрузку

1.  Нажмите сочетание клавиш `Win + R` на клавиатуре, чтобы открыть окно «Выполнить».
2.  В появившемся окне введите команду `shell:startup` и нажмите **Enter**. Откроется системная папка автозагрузки текущего пользователя.
3.  Создайте **ярлык** для вашего `.exe` файла (или `.ahk` скрипта) и переместите этот ярлык в открывшуюся папку. 
*(Не копируйте сам .exe файл, лучше скопировать именно ярлык на него).*
4.  Готово! Теперь скрипт будет автоматически запускаться вместе с Windows.
